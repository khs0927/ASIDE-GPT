# Evidence contract

Before reporting a browser task as complete, collect enough evidence to support the claim:

- final URL or connected-app source;
- page title, record name, or equivalent context;
- important extracted values;
- observation timestamp;
- actions actually performed;
- confirmation status;
- screenshots or source links when useful.

`packages/evidence` validates the required fields without storing page content or credentials. Evidence can show that a task is blocked, awaiting approval, or declined; it is not required to pretend that every task succeeded.
