# Security

The active ASIDE-GPT package is mobile-only and has no local execution service. Security rules for untrusted web content, credential handling, approvals, least privilege, and evidence are documented in [docs/SECURITY.md](docs/SECURITY.md).

The previous gateway/node implementation is archived under `legacy/local-node/` and is not part of the default install, build, test, or deployment path. Do not deploy it as a prerequisite for the mobile-only architecture.
