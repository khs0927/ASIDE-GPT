# Archived local-node architecture

This directory preserves the pre-2026-09-12 gateway/node implementation for historical reference. It is not an active workspace, dependency, deployment target, or supported mobile-only path.

The archived code required a persistent user-controlled machine running the ASIDE-GPT gateway, node agent, local Aside CLI, and local browser. The active architecture in the repository root uses ChatGPT Work as orchestrator and Work's native cloud browser; see [../../README.md](../../README.md).

Do not copy its environment variables, start commands, or tunnel instructions into a mobile-only deployment. Git history is retained so the old design remains auditable.
